# Cookies Bar

With this lightweight plugin you can display a cookie compliance bar (banner) at the bottom of your site.

You could install this plugin if your site uses cookies or collects personal visitor data via, for example, a form.

Cookies are set for (temporary) storing data, such as:

- User preferences
- The content of a shopping cart
- Site analytics

The plugin comes with various settings (to style the bar) and makes it possible to include a link to your Privacy Policy.
